## 🎮 Controls

### Movement (Bottom-Left Panel)
```
      ⬆️
   ⬅️ [•] ➡️
      ⬇️
```

- **⬆️ Forward** - Move toward the front of the pool
- **⬇️ Backward** - Move toward the back of the pool
- **⬅️ Left** - Move to the left
- **➡️ Right** - Move to the right

### Weight Adjustment (Bottom-Left Panel)
```
Weight: +/- X.X kg
Status: [NEUTRAL/RISING/SINKING]

[- 1 kg]  [+ 1 kg]
      [RESET]
```

- **- 1 kg** - Remove weight (become lighter, rise)
- **+ 1 kg** - Add weight (become heavier, sink)
- **RESET** - Return to 0 kg (neutral buoyancy)

### Buoyancy Status Colors:
- 🟢 **GREEN (NEUTRAL)** - Perfect balance, floating in place ✅
- 🟡 **YELLOW (RISING)** - Too light, moving upward
- 🔴 **RED (SINKING)** - Too heavy, moving downward

## 📋 How to Play

### Step 1: Open Task Panel
Click the **"📋 Tasks"** button in the top-right corner to see all available missions.

### Step 2: Select a Mission
Click **"START MISSION"** on any task. The panel will close and the mission becomes active.

### Step 3: Adjust Your Weight
Use the weight controls to reach the target weight shown in the task info panel.

**Example:** Task requires 0 kg (±1 kg)
- If you're at +2 kg (RED/SINKING) → Click **[- 1 kg]** twice
- If you're at -2 kg (YELLOW/RISING) → Click **[+ 1 kg]** twice
- When at 0 kg (GREEN/NEUTRAL) → You're ready!

### Step 4: Navigate to Position
Use the arrow buttons to move your astronaut to the correct location for the task.

### Step 5: Complete the Mission
When you're at the correct weight and position, click the **"✓ COMPLETE TASK"** button.

**Success:** ✅ Task completed! Points added to your score.
**Failure:** ❌ Adjust your weight to match the target and try again.

### Step 6: Next Mission
Your score updates automatically. Click **"📋 Tasks"** to select the next mission!

- Click weight buttons one at a time
- Wait for status to update

## 🔧 Troubleshooting

### Game Issues:

**❓ Astronaut not moving?**
- Click arrow buttons multiple times
- Ensure you're in NBL Training mode (not Cupola View)
- Hard refresh: `Ctrl + Shift + R`

**❓ Can't complete task?**
- Check weight is within tolerance range shown
- Look for GREEN status indicator
- Read task requirements carefully

**❓ Buttons not responding?**
- Click directly on button text
- Wait for page to fully load
- Check browser console (F12) for errors

**❓ Weight not changing?**
- Each click changes weight by 1 kg
- Watch the weight display update
- Try RESET button to start fresh

**❓ Task panel won't open?**
- Click the "📋 Tasks" button in top-right
- Refresh page if stuck
- Try different browser (Chrome recommended)

### Performance Issues:

**Game running slow?**
- Close other browser tabs
- Lower browser zoom level
- Update graphics drivers
- Use Chrome or Edge browser

**3D scene not rendering?**
- Enable WebGL in browser settings
- Update browser to latest version
- Try incognito mode
- Check hardware acceleration is enabled

## 🎓 Learning About NASA NBL

### Real NBL Facts:
- **Location:** Sonny Carter Training Facility, Houston, Texas
- **Pool Size:** 40 feet deep, 202 feet long, 102 feet wide
- **Water Volume:** 6.2 million gallons
- **Training Ratio:** 7 hours underwater = 1 hour spacewalk
- **Spacesuit Weight:** ~300 pounds (136 kg)
- **Safety:** Multiple scuba divers assist each training session

### Why Underwater Training?
Water provides neutral buoyancy that simulates the weightlessness of space. Astronauts wear weighted spacesuits and practice:
- EVA (Extravehicular Activity) procedures
- Tool handling in bulky gloves
- Module assembly and repairs
- Emergency scenarios
- Team coordination

### Real NASA Training:
This game simulates actual NBL training tasks that astronauts perform, including:
- Moving through airlocks
- Solar panel maintenance
- Equipment retrieval
- Module connections
- Surface traversal (lunar simulation)

## 🎮 Game Mechanics Explained

### Buoyancy Physics:
The game simulates real underwater physics:
- **Positive Weight (+)** → You sink downward
- **Negative Weight (-)** → You rise upward
- **Neutral Weight (0)** → You float in place

### Movement System:
- Horizontal movement (forward/back/left/right)
- Vertical movement (automatic based on weight)
- Combined 3D navigation

### Task Completion Logic:
1. Weight must be within tolerance range
2. Position must be appropriate for task
3. Task must be active (started)
4. Click complete button when ready

### Scoring Logic:
- Points awarded only on first completion
- Failed attempts don't reduce score
- Each task worth fixed points
- Total score is cumulative
